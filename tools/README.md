# 시뮬 / 회귀 테스트 (tools/)

게임 실행 파일(index.html)과 무관한 개발용 도구입니다. Node.js만 있으면 됩니다.

- `simlib.js`: 헤드리스 시뮬 라이브러리. 실제 게임 루프를 가짜 시간(50ms 프레임)으로 돌리고 그리기만 끕니다. 시드 고정이라 같은 시드면 같은 결과.
- `sim.js`: 전체 시뮬. `BAL_FILE=<index.html 경로> node sim.js cheap+upg2 200`
  - cheap = 살 수 있는 가장 싼 영웅부터 구매, upg2 = 환생 강화(등불 심지/불씨/규율/신속) 2단계. `cheap`만 쓰면 강화 없음.
  - 스킬 수동 사용 없음, 유물/사건/각성은 자동 선택. 파도 40 상한.
- `classes.js`: 클래스별 4기 시너지 영향. `BAL_FILE=... node classes.js 40 2` (판 수, 강화 단계)
- `regress.js`: 간이 회귀 테스트(시너지, 각성, 그리기 품질 낮음/높음, 도감/기록판 오류 없음). 경로는 /home/sandbox/abyss-lantern/index.html 고정이므로 필요하면 파일 안의 경로를 수정하세요.

## 기준 수치 (R110 빌드, 도달 파도, 150판, 시드 1000+i)
- cheap+upg2: 평균 16.7 / p10 15 / 중앙 17 / p90 18
- cheap+upg0: 평균 13.1 / p10 10 / 중앙 14 / p90 17
- 보스 단독 W10, cheap, 200판 격파율: 수호자 197 / 격랑 196 / 포식자 200 / 폭군 197 (군주는 별도)
- 참고(오래된 기준, R65): cheap+upg2 200판 평균 16.1, cheap 100판 평균 12.3

표본 오차는 약 ±0.3~0.5파도입니다. 이후 변경은 같은 명령으로 전/후를 비교하세요. 보스 벤치는 난수(Math.random)가 섞여 같은 조건에서도 격파율이 ±2%p 흔들립니다.
- `bossbench.js` (R93): 보스 5종 단독 측정. `BAL_FILE=<html> node bossbench.js <보스파도W> <판수> [cheap|1G|3G] [startAt]`. 임시 복사본에서 해당 파도의 보스를 강제하므로 게임 파일은 그대로. 처치시간, 등불 피해%, 패배율, 폭군/군주 격노 구간 피해를 출력. simlib의 onFrame/stopWhen 훅을 사용.
