# 심연의 등불 (Abyss Lantern)

> SNKRX 오마주 오리지널 웹게임 — 코어 수호 + 진형 배치 오토 배틀

**▶ 플레이: https://sigco3111.github.io/abyss-lantern/**

어둠의 바다 '심연' 한가운데 떠 있는 마지막 등대. 등대의 심장 **코어**를 몰려오는 어둠으로부터 지켜내세요. 영웅을 고용하고 진형을 짜면 전투는 자동으로 진행됩니다.

## 게임 방법

1. **정비 페이즈**: 골드로 영웅 카드를 구매하고, 등대 주변 슬롯 링을 클릭해 배치하세요. 배치된 유닛을 다시 클릭하면 들어올려 재배치할 수 있습니다.
2. **파도 시작** (또는 스페이스): 심연의 무리가 사방에서 몰려옵니다. 유닛들이 자동으로 전투합니다.
3. 같은 영웅 2장이 있을 때 한 장을 더 사면 **합체(★업그레이드)** 됩니다.
4. 같은 클래스를 모으면 **시너지 세트 효과**가 발동합니다 (검성/궁수/마법사, 각 2/4단계).
5. 골드 10G당 웨이브 종료 시 **이자 +1** (최대 +5).
6. 코어가 파괴되면 런 종료. 최고 기록(파도)이 저장됩니다.

## R1 범위

- 영웅 6종 (검성/궁수/마법사 3클래스), 슬롯 16칸 (내륜 6 + 외륜 10)
- 적 3종, 무한 웨이브 스케일링
- 상점 5슬롯 / 리롤 / 이자 / 합체(★1→★3)
- 타격감: 파티클, 대미지 숫자, 화면 흔들림, 넉백, 히트스톱(보스급 처치)
- 회전하는 등대 빛줄기 연출, 최고 기록 로컬 저장, FPS 표시

## 기술

- 단일 `index.html` / Canvas 2D / 바닐라 JS — 빌드 없는 정적 서버리스
- 파티클 객체 풀링, 한글 웹폰트(Noto Sans KR)
- `?autotest=1` 파라미터로 자동 부팅 테스트 모드 지원

## 로드맵 (설계서 기준)

R2 타격감 고도화 → R3 클래스 10종 + 영웅 확장 → R4 마우스 조준 스킬 → R5 위임 자동화 + 오프라인 정산 → R6 대시보드/도감/환생(재점화)
