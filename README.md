# 심연의 등불 (Abyss Lantern)

> SNKRX 오마주 오리지널 웹게임 — 군집 이동 + 진형 오토 배틀

**▶ 플레이: https://sigco3111.github.io/abyss-lantern/**

등불을 든 리더와 수호단이 어둠의 바다 '심연'에서 몰려오는 파도를 막아냅니다. 영웅을 고용하고 진형을 짜면 전투는 자동으로 진행됩니다.

## 게임 방법

1. **정비 페이즈**: 골드로 영웅 카드를 구매하면 수호단에 즉시 합류합니다. 진형 프리셋(원형/전열/쐐기/산개)을 고르세요. 왼쪽 수호단 명단에서 유닛을 클릭하면 개별 행동(진형/돌격/고정)이 바뀝니다.
2. **파도 시작** (또는 스페이스): 어둠이 사방에서 몰려옵니다. 유닛들이 자동으로 전투합니다.
3. **직접 조종 / 위임**: 전투 중 마우스 드래그나 WASD로 리더(등불)를 직접 이끌 수 있습니다. 스페이스로 수동↔위임을 즉시 전환하고, 조종을 멈추면 잠시 후 자동으로 위임에 복귀합니다. 위임 모드 4종: 공격형 / 방어형 / 카이팅형 / 수집형(골드 오브 회수).
4. 같은 영웅 3장은 **합체(★업그레이드)**, 같은 클래스를 모으면 **시너지 세트 효과** (검성/궁수/마법사, 각 2/4단계).
5. 처치한 적은 **골드 오브**를 떨굽니다. 가까이 가면 자석처럼 회수됩니다. 골드 10G당 웨이브 종료 시 **이자 +1** (최대 +5).
6. 등불이 꺼지면 런 종료. 최고 기록(파도)이 저장됩니다.

## R2 범위

- 군집 이동: 리더(등불 운반자) + 수호단이 진형 오프셋으로 추종 (스프링 물리)
- 리더 직접 조종(마우스 드래그/WASD) ↔ 위임 4모드, 스페이스 즉시 전환, 무입력 시 자동 위임 복귀
- 진형 프리셋 4종 + 영웅별 개별 행동(진형/돌격/고정)
- 영웅 6종 3클래스(검성/궁수/마법사, 실루엣 구분: 다이아/삼각/육각), 합체 ★3, 시너지 세트
- 골드 오브 드롭/자석 회수
- 타격감: 스쿼시&스트레치, 피격 플래시, 잔상(리더/고속 유닛), 충돌 스파크, 화면 흔들림, 히트스톱, 파티클
- 후처리: 비네트 + 등불 중심 조명, 회전 빛줄기
- 최고 기록 로컬 저장, FPS 표시

## 기술

- 단일 `index.html` / Canvas 2D / 바닐라 JS — 빌드 없는 정적 서버리스
- 투사체 선분-원 스윕 충돌(고속 터널링 방지), 파티클 객체 풀링, 한글 웹폰트(Noto Sans KR)
- `?autotest=1` 자동 부팅 테스트, `&speed=N`(1~8) 시뮬레이션 배속 검증

## 로드맵

R3 클래스/영웅 확장 → R4 마우스 조준 스킬 → R5 위임 자동화 고도화 + 오프라인 정산 → R6 대시보드/도감/환생(재점화)
